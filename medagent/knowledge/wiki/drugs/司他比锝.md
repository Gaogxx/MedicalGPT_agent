# 司他比锝（technetium Tc-99m sestamibi）

> 未经医生 / 药师审核，仅供参考；剂量以所用药品的说明书或医嘱为准。

## 要点

用途：用于心肌成像检测冠脉疾病及评估功能，或作为乳腺 X 线摄影后二线诊断药物。
<sub>来源：模型据本条目适应症 / 禁忌 / 不良反应分段概括（compiler，已过数字、程度词与频率词、药师复核）</sub>

## 适应症

心肌成像：用于通过定位心肌缺血（可逆性缺损）和梗死（不可逆性缺损）来检测冠状动脉疾病；评估心肌功能，为患者管理决策提供信息。乳腺成像：作为乳腺 X 线摄影后的二线诊断药物，用于平面成像，协助评估乳腺 X 线摄影异常或可触及乳腺肿块患者的乳腺病变。不用于乳腺癌筛查、确认恶性肿瘤存在与否，亦非活检替代方案。

<sub>来源：美国 FDA 说明书（模型译写，已核对） set_id=8626e756-767a-4a14-9188-658b58185254 effective=20250908</sub>

## 用法用量

心肌显像：静脉注射单次剂量 370–1110 MBq（10–30 mCi）。乳腺显像：静脉注射单次剂量 740–1110 MBq（20–30 mCi）。（依据美国 FDA 说明书，给药途径 PARENTERAL，国内说明书可能不同）

<sub>来源：美国 FDA 说明书（模型译写，已核对） set_id=8626e756-767a-4a14-9188-658b58185254 effective=20250908</sub>

## 不良反应

常见不良反应（发生率≥0.5%）：味觉倒错（7.1%）、全身不适（0.8%）、心血管事件（3.3%）、胸痛/心绞痛（2.1%）、ST 段改变（1.3%）、头痛（0.2%）、恶心（0.1%）、嗅觉异常（0.5%）。严重不良反应（发生率≤0.5%）：癫痫样症状、短暂性关节炎、血管性水肿、心律失常、头晕、晕厥、腹痛、呕吐、严重过敏反应（呼吸困难、低血压、心动过缓、乏力、呕吐）。

<sub>来源：美国 FDA 说明书（模型译写，已核对） set_id=8626e756-767a-4a14-9188-658b58185254 effective=20250908</sub>
