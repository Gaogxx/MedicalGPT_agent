# 直肠癌

> 未经医生 / 药师审核，仅供参考；剂量以所用药品的说明书或医嘱为准。

## 说明书适应症提到本病的药物（不是治疗推荐或排序，用药须遵医嘱）

- [奥沙利铂](../drugs/奥沙利铂.md)：晚期结直肠癌的治疗
- [帕尼单抗](../drugs/帕尼单抗.md)：适用于成人野生型 RAS（KRAS 和 NRAS 均为野生型）转移性结直肠癌
- [西妥昔单抗](../drugs/西妥昔单抗.md)：结直肠癌
- [卡培他滨](../drugs/卡培他滨.md)：结直肠癌
- [瑞戈非尼](../drugs/瑞戈非尼.md)：STIVARGA 适用于成人转移性结直肠癌（CRC）
- [康奈非尼](../drugs/康奈非尼.md)：联合 cetuximab 及氟尿嘧啶类化疗用于 BRAF V600E 突变转移性结直肠癌（mCRC）
- [伊匹单抗](../drugs/伊匹单抗.md)：MSI-H 或 dMMR 不可切除/转移性结直肠癌（联合 nivolumab）
- [纳武利尤单抗](../drugs/纳武利尤单抗.md)：MSI-H 或 dMMR 不可切除或转移性结直肠癌（联合 ipilimumab）
